Pi 是一个极简的终端编码工具。它保持核心最小化，通过 TypeScript 扩展、技能、提示模板、主题和 Pi 包进行扩展。

## 快速开始 Quick start

使用 npm 全局安装：

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
```

`--ignore-scripts` 在安装时禁用依赖生命周期脚本，pi 的正常安装无需安装脚本。

Linux 或 macOS 也可使用安装脚本：

```bash
curl -fsSL https://pi.dev/install.sh | sh
```

**卸载：**

```bash
npm uninstall -g @earendil-works/pi-coding-agent
```

pnpm、Yarn 或 Bun 安装的使用对应命令：`pnpm remove -g`、`yarn global remove`、`bun uninstall -g`。

安装后在项目目录中运行：

```bash
pi
```

使用 `/login` 通过订阅提供商认证，或在启动前设置 API Key（如 `ANTHROPIC_API_KEY`）。

首次运行的完整流程请参见[快速开始](快速开始.md)。
