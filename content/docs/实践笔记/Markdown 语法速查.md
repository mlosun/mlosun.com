## 标题

注意：所有符号都是英文输入法下的符号。井号加空格，几个井号就是几级标题，一级标题字体最大。

```text
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## 文本

```text
**加粗**
*斜体*
***粗斜体***
~~删除线~~
```

## 列表

**无序列表：** 减号/加号/星号 + 空格，三个符号均可，建议用减号。

```text
- 列表项 1
- 列表项 2
 - 嵌套列表项
- 列表项 3
```

**有序列表：** 数字 + 点 + 空格。

```text
1. 列表项 a
2. 列表项 b
 1. 嵌套项 b1
3. 列表项 c
```

**任务列表：** 方括号内空格代表未完成，`x` 代表已完成。

```text
- [ ] 未完成的任务
- [x] 已完成的任务
```

## 引用

```text
> 这是一段引用
>> 嵌套引用
```

## 链接

```text
[显示的文字](https://example.com)

直接链接：<https://github.com>

锚点链接：[链接文字][锚点名]
[锚点名]: https://example.com
```

## 图片

```text
![替代文本](图片路径 "可选的标题")

带链接的图片：[![替代文本](图片路径)](https://example.com)
```

## 表格

竖线分隔单元格，分隔行至少三个减号，冒号控制对齐。

```text
| 左对齐 | 居中对齐 | 右对齐 |
| :----- | :------: | -----: |
| AAA    |   BBB    |    CCC |
```

## 代码

**行内代码**：用反引号包裹，如 `` `code` ``。

**代码块**：用三个反引号包裹，可指定语言。

````text
```python
import numpy as np
def calc(a):
    return np.sqrt(a) * 3
```
````

## 脚注

```text
要添加脚注[^01]

[^01]: 脚注内容
```

## 分割线

三个或以上的减号、星号、下划线均可。

```text
---
***
___
```

## 注意事项

- 所有符号都是**英文输入法**下的符号
- 井号 `#` 后要加空格才是标题
