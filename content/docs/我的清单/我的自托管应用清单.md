> [!NOTE] 说明
> 本篇记录我自托管（Self-Hosted）的应用，按部署位置分类。

## 腾讯云

* [Flare](https://github.com/soulteary/docker-flare) — 轻量导航页
* [FreshRSS](https://github.com/FreshRSS/FreshRSS) — RSS 聚合阅读
* [Memos](https://github.com/usememos/memos) — 闪念与碎片化记录
* [Frp](https://github.com/fatedier/frp) — 内网穿透，远程访问群晖
* [EasyNode](https://github.com/chaos-zhu/easynode) — Web SSH 终端管理
* [Dataease](https://github.com/dataease/dataease) — 开源 BI 数据分析平台

## 群晖 NAS

* [MT Photos](https://mtmt.tech/) — AI 相册管理（付费）
* [qBittorrent](https://github.com/qbittorrent/qBittorrent) — PT 下载客户端
* [Watchtower](https://github.com/containrrr/watchtower) — Docker 容器自动更新
* [Uptime Kuma](https://github.com/louislam/uptime-kuma) — 自托管服务状态监控
* [DPanel](https://github.com/donknap/dpanel) — Docker 可视化管理面板
