## 👨‍💻 社区插件

### 🔗 集成与同步

1. [Git](https://github.com/Vinzent03/obsidian-git) 集成 Git 版本控制，实现自动同步与版本管理。
2. [Copilot](https://github.com/logancyang/obsidian-copilot) AI 助手插件，提供智能写作和编辑支持。
3. [Memos Sync](https://github.com/RyoJerryYu/obsidian-memos-sync) 笔记同步插件，支持跨设备同步。
4. [RSS Dashboard](https://github.com/amatya-aditya/obsidian-rss-dashboard) RSS 订阅仪表盘，方便管理和阅读 RSS 源。
5. [Digital Garden](https://github.com/oleeskild/obsidian-digital-garden) 数字花园插件，帮助构建知识图谱。
6. [Image auto upload](https://github.com/renmu123/obsidian-image-auto-upload-plugin) 自动上传图片到云存储，方便备份和分享。

### 🎨 界面与美化

1. [I18N](https://github.com/Obsidian-Forge/obsidian-i18n) 国际化插件，支持多语言笔记管理。
2. [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) 样式设置插件，支持自定义 Obsidian 的外观。
3. [Custom Font Loader](https://github.com/pourmand1376/obsidian-custom-font) 加载自定义字体，增强笔记的视觉效果。
4. [Rainbow-Colored Sidebar](https://github.com/Kovah/obsidian-rainbow-colored-sidebar) 侧边栏颜色插件，支持自定义侧边栏颜色。
5. [File Explorer Note Count](https://github.com/ozntel/file-explorer-note-count) 在文件浏览器中显示笔记数量，方便管理。

### ✨ 格式化渲染

1. [Tasks](https://github.com/obsidian-tasks-group/obsidian-tasks) 任务管理插件，支持创建和跟踪任务。
2. [Dataview](https://github.com/blacksmithgu/obsidian-dataview) 数据视图插件，支持从笔记中提取和显示数据。
3. [Components](https://cp.cc1234.cc/) （付费）可视化仪表盘插件，支持强大的自定义组件。
4. [Components Lock](https://github.com/zereazheng/obsidian-components-lock) 锁定 Components 页面，防止意外修改。

### 🛠️ 编辑体验

1. [Linter](https://github.com/platers/obsidian-linter) 强大的格式化笔记插件。
2. [Next TOC](https://github.com/RavenHogWarts/obsidian-next-toc) 显示当前文档阅读进度、目录及导航辅助功能的浮动面板。
3. [Markmind](https://github.com/MarkMindCkm/obsidian-markmind) 闭源的思维导图插件。
4. [Templater](https://github.com/SilentVoid13/Templater) 模板插件，支持快速生成重复内容。
5. [Number Headings](https://github.com/onlyafly/number-headings-obsidian) 自动为笔记标题编号，方便导航。
6. [Auto Link Title](https://github.com/zolrath/obsidian-auto-link-title) 自动获取粘贴链接的标题。
7. [VSCode Editor](https://github.com/sunxvming/obsidian-vscode-editor) 允许在 Obsidian 里像 VSCode 一样编辑代码文件。

### 🔧 功能扩展

1. [BRAT](https://github.com/TfTHacker/obsidian42-brat) 可以直接添加 Github 上的测试版插件/主题。
2. [Form Flow](https://github.com/vran-dev/obsidian-form-flow) 表单生成插件，支持创建交互式表单。
3. [Omnisearch](https://github.com/scambier/obsidian-omnisearch) 搜索插件，提供更强大的搜索功能。
4. [Excalidraw](https://github.com/zsviczian/obsidian-excalidraw-plugin) 手绘白板插件，支持自由绘制图形和流程图。
5. [Advanced Canvas](https://github.com/Developer-Mike/obsidian-advanced-canvas) 白板增强，提供更丰富的绘图和编辑功能。
6. [Multi Properties](https://github.com/technohiker/obsidian-multi-properties) 允许添加、编辑或删除多个笔记的属性。
7. [Export Image plugin](https://github.com/zhouhua/obsidian-export-image) 导出笔记为图片，方便分享和备份。

### 🧰 实用工具

1. [Imagine](https://github.com/AlbusGuo/albus-imagine) 强大的 Obsidian 图片管理插件。
2. [Calendar](https://github.com/liamcain/obsidian-calendar-plugin) 日历插件，用于管理和查看日期。
3. [CSV Lite](https://github.com/LIUBINfighter/csv-lite) 直接在 Obsidian 中查看和编辑 CSV 文件的插件。
4. [CSS Editor](https://github.com/Zachatoo/obsidian-css-editor) 允许直接编辑 `.obsidian/snippets/` 中的 CSS 文件。
5. [Gantt Calendar](https://github.com/sustcsugar/obsidian-gantt-calendar) 一个强大的 Obsidian 任务管理和日历插件。
6. [Floating Settings](https://github.com/wambo121/Floating-Settings-for-Obsidian) 在新窗口打开设置界面。
