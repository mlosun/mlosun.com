分享我日常使用的 VSCode 扩展，按用途分类整理。

## Python 开发

- [Black Formatter](https://marketplace.visualstudio.com/items?itemName=ms-python.black-formatter) — Python 代码格式化工具，统一代码风格
- [Pylance](https://marketplace.visualstudio.com/items?itemName=ms-python.vscode-pylance) — Python 语言服务器，提供智能提示和类型检查
- [Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python) — Python 核心扩展，集成调试和代码检查
- [Python Environments](https://marketplace.visualstudio.com/items?itemName=ms-python.vscode-python-envs) — 统一管理 Python 解释器和虚拟环境

## Markdown 和笔记

- [Markdown All in One](https://marketplace.visualstudio.com/items?itemName=yzhang.markdown-all-in-one) — 快捷键、目录、自动预览等 Markdown 全能工具
- [Markdown Notebook](https://marketplace.visualstudio.com/items?itemName=ms-vscode.vscode-markdown-notebook) — Notebook 模式编辑 Markdown
- [Markdown Preview Enhanced](https://marketplace.visualstudio.com/items?itemName=shd101wyy.markdown-preview-enhanced) — 增强预览，支持公式、图表、导出
- [Markmap](https://marketplace.visualstudio.com/items?itemName=gera2ld.markmap-vscode) — 将 Markdown 转换为思维导图
- [Foam](https://marketplace.visualstudio.com/items?itemName=foam.foam-vscode) — 基于 Markdown 和 Wikilink 的知识管理工具
- [dendron](https://marketplace.visualstudio.com/items?itemName=dendron.dendron) — 层级化笔记工具
- [Front Matter CMS](https://marketplace.visualstudio.com/items?itemName=eliostruyf.vscode-front-matter) — 内置 CMS，支持 Hugo、Jekyll 等静态站点

## 数据文件

- [Excel Viewer](https://marketplace.visualstudio.com/items?itemName=GrapeCity.gc-excelviewer) — 查看和编辑 Excel 表格
- [SQLite Viewer](https://marketplace.visualstudio.com/items?itemName=qwtel.sqlite-viewer) — 查看和管理 SQLite 数据库

## 主题和图标

- [Maple Theme](https://marketplace.visualstudio.com/items?itemName=subframe7536.theme-maple) — 彩色主题，亮/暗模式，低饱和度
- [Material Icon Theme](https://marketplace.visualstudio.com/items?itemName=PKief.material-icon-theme) — Material Design 文件图标

## 工具和实用程序

- [Chinese (Simplified) Language Pack](https://marketplace.visualstudio.com/items?itemName=MS-CEINTL.vscode-language-pack-zh-hans) — 简体中文语言包
- [Even Better TOML](https://marketplace.visualstudio.com/items?itemName=tamasfe.even-better-toml) — TOML 配置文件支持
- [Open](https://marketplace.visualstudio.com/items?itemName=sandcastle.vscode-open) — 用系统默认程序打开当前文件
- [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) — 多语言代码格式化
- [Remote - SSH](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-ssh) — 远程连接服务器编辑文件
